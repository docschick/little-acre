# Little Acre workflow

- Make future changes on a new feature branch and open a GitHub pull request for Sandra to review.
- Do not push changes directly to `main` or merge pull requests unless Sandra explicitly asks.
- Preserve existing browser garden records and maintain compatibility with older JSON backups.
- Run `npm test` for changes to planting dates, rotations, reminders, or backup validation. Keep documentation-only validation focused on the affected references.
